# Al Salam Resort

A professional landing page designed using **Next.js** and **React** for **Al Salam Resort**.  
This project is fully optimized for **Arabic language**, featuring a responsive design and high performance.

## Current Features:
- Full support for Arabic (RTL layout).
- Modern and responsive design for all devices.
- High loading speed with performance optimizations.
- Easy navigation to enhance user experience.

## Upcoming Features:
- Integration of a full booking system for the resort.
- Addition of an interactive map for the resort's location.
- Further enhancements to user experience for seamless interaction.

## Technologies Used:
- **Next.js**: For server-side rendering and front-end development.
- **React**: For building reusable UI components.
- **Tailwind CSS**: For fast and responsive design.
- **RTL Support**: Ensuring right-to-left layout compatibility.
